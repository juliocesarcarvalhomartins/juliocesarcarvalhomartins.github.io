Sistema de Chamados

Projeto de Help Desk desenvolvido em MySQL 8.0 para representar o fluxo de abertura e atendimento de chamados. O banco relaciona setores, funcionários, chamados, categorias, prioridades, status, técnicos e atendimentos, com modelagem conceitual e lógica, chaves PK/FK e consultas SQL para análise e acompanhamento.

O que foi aplicado

Modelagem de dados

Construção do MER e do modelo lógico, com relacionamentos 1:N e definição das entidades, atributos e cardinalidades.

Integridade relacional

Uso de chaves primárias e estrangeiras, AUTO_INCREMENT, NOT NULL e DEFAULT para estruturar e relacionar os dados.

Fluxo de Help Desk

O modelo permite identificar quem abriu o chamado, setor do funcionário, categoria, prioridade, status e técnico responsável pelo atendimento.

Dados de teste

O banco foi populado com funcionários, técnicos, chamados e atendimentos para validar relacionamentos e consultas no MySQL Workbench.

Consultas SQL desenvolvidas

SELECT + WHERE

Listagem de chamados e filtros por status.

ORDER BY

Ordenação de funcionários em ordem alfabética.

GROUP BY + COUNT

Contagem de chamados por categoria.

SUM + AVG

Total geral e média de chamados por funcionário.

MAX + MIN

Maior e menor quantidade de chamados por categoria.

INNER / LEFT JOIN

Visões relacionando chamados, funcionários, setores, categorias, prioridades, status, técnicos e atendimentos.

Resultado

O projeto foi implementado e testado no MySQL Workbench. O banco sistema_chamados, as tabelas, dados, chaves estrangeiras e consultas foram validados sem erros, permitindo visualizar o fluxo completo de cada chamado.
